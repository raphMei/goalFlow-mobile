# GoalFlow Mobile

Assistant personnel mobile qui transforme vos objectifs en **tâches quotidiennes guidées**.

## Stack

- React Native
- Expo
- TypeScript
- Expo Router

## Statut

✅ **Expo initialisé** — structure `src/` en place. Features métier à venir (voir `docs/FEATURES.md`).

## Démarrage rapide

```bash
cp .env.example .env
npm start
```
