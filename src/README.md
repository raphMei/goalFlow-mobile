# `src/`

Code source de GoalFlow Mobile.

| Dossier           | Rôle                                         |
| ----------------- | -------------------------------------------- |
| `app/`            | Routes et layouts Expo Router                |
| `domain/`         | Logique métier pure (sans React, sans I/O)   |
| `features/`       | Écrans et UI liés à une fonctionnalité       |
| `infrastructure/` | Stockage, API, intégrations externes         |
| `shared/`         | UI générique, thème, hooks et utils partagés |

Alias : `@/` → `src/` (ex. `@/domain/planning/...`).
