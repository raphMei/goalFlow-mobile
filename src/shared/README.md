# `src/shared/`

Éléments **réutilisables** entre features : pas de logique métier spécifique à un écran.

| Sous-dossier  | Contenu                                   |
| ------------- | ----------------------------------------- |
| `components/` | Button, Card, AppText, ScreenContainer…   |
| `hooks/`      | Hooks génériques (non liés à une feature) |
| `theme/`      | Couleurs, typo, spacing, tokens           |
| `utils/`      | Fonctions pures utilitaires               |
