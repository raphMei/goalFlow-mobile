# GoalFlow — UI / UX Guide

## Direction visuelle

Le design doit être :

- humain ;
- vivant ;
- motivant ;
- coloré ;
- premium ;
- mobile-first ;
- clair ;
- pas surchargé.

L’app ne doit pas ressembler à :

- une todo list froide ;
- une app SaaS corporate ;
- un dashboard trop chargé ;
- une app fitness agressive.

Elle doit donner l’impression d’un coach personnel chaleureux.

## Principe visuel

Chaque objectif a :

- une couleur ;
- une icône ;
- une énergie ;
- une identité.

## Écran principal

L’écran principal est Aujourd’hui.

Il doit afficher :

- Bonjour David 👋
- date ;
- type de journée ;
- rythme du jour ;
- progression ;
- objectifs du jour ;
- tâches chronologiques.

Ne jamais surcharger l’écran Aujourd’hui.

Le détail complet doit être dans la page détail de tâche.

## Navigation

Bottom nav avec 4 onglets :

- Aujourd’hui
- Objectifs
- Progression
- Profil

Planning et réglages sont dans Profil.

## Tâches

Chaque tâche affiche :

- icône ;
- heure ;
- titre ;
- catégorie ;
- durée ;
- objectif lié ;
- bouton principal ;
- checkbox.

## Détail tâche

Chaque tâche peut avoir :

- étapes ;
- timer ;
- recette ;
- exercices ;
- log ;
- notes ;
- bouton terminer ;
- bouton reporter ;
- bouton version courte.

## Onboarding

L’onboarding doit être conversationnel.

Une question par écran.

Pas de formulaire long.

Réponses sous forme de cartes colorées.

Questions principales :

- objectifs ;
- priorité ;
- niveau ;
- temps disponible ;
- planning ;
- contraintes ;
- moments préférés ;
- rythme ;
- alimentation si nécessaire ;
- résumé avant génération.
